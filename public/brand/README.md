# The Nurts brand assets (game)
- logos/: trimmed, transparent official logo variants (PNG + WebP; 1024 px and @512). Source: brand uploads 1–7.png.
- chars/: Nurts Kids sprites cut out from the official turnarounds. Poses: front, threequarter, side (720 px); busts happy, excited, worried, cross (400 px). Use the .webp files in-game; the .png files are masters.
- _cutout-script.py: how the sprites were made (rembg isnet-general-use + mask cleanup), kept for re-runs.
Brand rule: public-facing copy always says "The Nurts".
